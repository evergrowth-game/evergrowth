# Raiders Mod

This mod is extracted and adapted from the **"Wilhelmines People"** (`people`) mod, originally created by **Liil** (Skandarella).

It implements the raider, pirate, and plunderer mechanics from the original mod, including their respective sounds, models, textures, and items (such as the Plunderer Crossbow, Flask, and Stick).
